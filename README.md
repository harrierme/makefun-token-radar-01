Token Radar — the best token launch radar: it reads a sealed snapshot of pre-token protocols, scores each one with the model in `lib/model.ts`, writes the ranked board to `/output/board.json`, and ships a static dashboard page showing the same numbers.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
