How to farm it

    This protocol records no token in the snapshot. That is not proof it has none.

    Value model: implied value = TVL × 0.50 × (1 + 7-day change, clamped to −15% / +40%) × (1 + years listed, capped at 3, × 0.10). A launch is priced near half the value the protocol already secures; growth bends it, a longer track record adds a little.

    Coverage: every protocol on the snapshot's watchlist is on this board, plus 161 more below the $50M floor that pass the same rule. Centralised exchanges, bridges, liquid staking and restaking products, wrapped or staked products, and versioned names are left out: they are products of a token that already trades, not protocols waiting for one.
